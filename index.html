Overview

NapcoILockSDK provides a comprehensive framework for connecting, controlling, and managing Napco smart locks using Bluetooth in your mobile app. It handles credential decoding, lock operations, and status monitoring so you can focus on your app’s UI and business logic.

The SDK simplifies the integration of smart locks into your applications by providing a set of tools and APIs for connection, control, and interaction with locks. Key components include the Credential struct for handling authentication data, ImportUtility for importing and decoding credentials, the iLock class for managing lock operations, and enums for lock states. With delegate-driven communication, you can monitor lock status, RSSI, and handle operational mismatches effectively. The SDK is designed for flexibility and can be integrated into smart home or access control systems.

Licensing & Access

To use NapcoILockSDK in your mobile app, you must obtain an AppID from Napco. Please contact Napco to request access and provisioning details.

When you reach out, have the following ready to speed up approval:

  • Company name and primary technical contact (name & email)
  • Platform & identifiers: iOS Bundle Identifier and/or Android ApplicationId (package name)
  • App name, intended use case, and target deployment (pilot, production)
  • Environment needs (Development and/or Production AppIDs)
  • Any test device details (optional): model, OS version

After approval, Napco will issue your AppID. You will reference this AppID during SDK initialization, and it may be scoped per environment. Access may be subject to additional agreements or security validation.
